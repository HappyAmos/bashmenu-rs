# BashMenu-RS Development Invariants & Guidelines

## 1. Mandatory Git Commit & Push Workflow
- **Commit & Push Requirement:** Every completed task, bug fix, feature, or refactor must conclude with a descriptive commit (`git commit -m "..."`) pushed directly to GitHub (`git push origin main`). Never leave changes uncommitted or unpushed.
- **Remote CI Verification:** After pushing to GitHub, verify remote CI passes using the GitHub CLI:
  - Query run ID: `gh run list --workflow=rust-app.yml --limit 1 --json databaseId -q '.[0].databaseId'`
  - Watch run: `gh run watch <ID>` (always pass an explicit ID to avoid interactive hangs).

## 2. Configuration & State Persistence
- **Single Source of Truth Config Path & Project Root Defaults:** User configs reside in `~/.config/bashmenu/` (`{bashmenu_dir}`), while `{dev_dir}` dynamically resolves git repository root. Original default config files (`bashmenu.yml`, `bashmenu.mnu`, `bashmenu.themes`, `shortcuts.yml`, `cheat.yml`) reside strictly in project root. The `/tests/fixtures` directory has been removed and must never be reintroduced; all test harnesses, fallbacks, and loaders reference root files directly.
- **Repository Root Mode (`--repo` / `-r`):** Passing `--repo` or `-r` to `bashmenu` forces loading `bashmenu.yml`, `bashmenu.mnu`, `bashmenu.themes`, and `shortcuts.yml` directly from repository root (`resolve_dev_dir`) rather than user config or working directory.
- **Direct Linux Framebuffer TrueColor & Full-Resolution Image Mode (`--image` / `-i`):** On Linux console with accessible `/dev/fb0` (`settings.framebuffer: auto | true | image`), `FramebufferDevice` renders Ratatui's buffer in 24-bit TrueColor directly into `/dev/fb0` while `TerminalOutput` suppresses stdout ANSI writes. Default uses character-block wallpaper (`▀`/`▛`); passing `--image` or `-i` renders full-resolution pixel wallpaper onto `/dev/fb0` composited beneath TrueColor TUI.
- **Environment Overview Macro (`{env}` / `{environment}`) & Application Version (`{version}`):**
  - `{version}` resolves strictly to root `Cargo.toml` (`workspace.package.version`), with `env!("CARGO_PKG_VERSION")` fallback. `{app.version}` is disabled in dot-path resolution.
  - `{env}` / `{environment}` loads `assets/about.md`, extracts YAML frontmatter `title` for modal title, and interpolates placeholders (`{version}`, `{color_mode}`, `{tty_mode}`, `{bashmenu_yml}`, `{bashmenu_mnu}`, `{bashmenu_themes}`, `{shortcuts_yml}`, `{cheat_yml}`).
  - Intercepted across actions, commands, scripts, messages, prompts, or types, displaying an interactive `MessageModal` with the environment table.
- **Menu Editor Add & Delete Key Parity (`menuedit`):** In `menuedit`, <kbd>a</kbd> or <kbd>Insert</kbd> adds a new item node (opening type picker); <kbd>d</kbd> or <kbd>Delete</kbd> deletes selected node (prompting confirmation).
- **Config Header Preservation:** When saving `bashmenu.yml`, ALWAYS use `bashmenu_core::save_config(path, config)` rather than raw YAML dumps to preserve top-level `CONFIG_HEADER` comment documentation.
- **Configuration Structural Integrity Invariant (`bashmenu.yml`, `BashMenuConfig::set_value`):** Writes via `BashMenuConfig::set_value` must NEVER write dot-delimited paths as flat literal keys containing periods into `Settings.extra`, `BashMenuConfig.extra`, or `user` maps. All multi-level paths must map to strongly-typed fields or decompose recursively into nested YAML mappings (`serde_yml::Mapping`).
- **Theme Editor Save Invariant (`themeedit`):** <kbd>Ctrl+S</kbd> saves directly to disk whenever `theme_name` is set. Only untitled themes divert to "Save As". <kbd>Ctrl+A</kbd> opens "Save As".
- **Alphabetical Theme Ordering & Palette Derivation:** Theme pickers (`ThemePickerModal`), theme cycling, and `save_themes()` must always sort themes alphabetically (case-insensitively). In `themeedit`, <kbd>F5</kbd> auto-derives theme colors (including `plugin` text color) from the wallpaper image and clears view-specific sub-table overrides (`menu_editor`, `editor`, `modals`).
- **Theme Editor Glyph Search Shortcut Invariant (`themeedit` <kbd>Ctrl+P</kbd>):** Pressing <kbd>Ctrl+P</kbd> or clicking `[Ctrl+P] Glyphs` in `themeedit` launches Nerd Font & Emoji search (`InputModal` titled "Search Nerd Font & Emoji"). Queries execute `run_glyphs_search(&term)` via `scripts/glyphs.sh` (falling back to built-in cheat sheet) displayed in `HelpModal`. Intercepted inside `IndicatorInput` and `DefaultIconInput` modals.
- **Theme Default Icon & Universal Menu Item Fallback Invariant (`default_icon`):** Every theme in `bashmenu.themes` must define `default_icon: '{nf:>:#f105}'`. Menu items lacking an explicit icon adopt the active theme's `default_icon` across `bashmenu` (`MenuView`), `menuedit` (tree rows, property inspector, item editor prefill/preview), and `themeedit` (preview menu item 3).
- **Colocated Swap Files (`bashedit`):** Swap files `.<filename>.swp` must reside in the exact directory as the target file (never `/tmp` or central dirs). Clean exit removes the swap file. On startup, dead PID swap files prompt recovery; active PID swap files warn of collision and open in read-only mode.
- **Theme Color Pair Transparency (-1):** In `bashmenu.themes`, background value `-1` in style pairs (e.g. `[255, -1]`) signifies transparent / container-inherited background. Never map `-1` to `Color::Reset` in style pairs as it emits ANSI `\x1b[49m` over colored surfaces.
- **3-Tier Theme Palette Parity (256 / 16 / 8):** Themes in `bashmenu.themes` must maintain token parity across tiers `256`, `16`, and `8`. Auto-derivation (`derive_colors_from_wallpaper`), new themes (`Theme::monochrome()`), and token updates (`set_color_token_value`) downsample colors into valid ANSI 16/8-color constants (`COLOR_*`) via perceptual luminance and HSV hue classification without view-specific sub-table overrides.
- **Theme Selection Highlight Bar & Highlight Text Invariant (`highlight`, `highlight_text`):** In `bashmenu.themes`, `highlight: [fg, bg]` defines selection (index 0 fg, index 1 margin-to-margin bg). In `themeedit`, setting "Highlight Color" (`highlight`) updates index 1 (`bg`) with auto high-contrast index 0 (`fg`). Setting "Highlight Text Color" (`highlight_text`) updates index 0 (`fg`) and `highlight_text` palette key. Menu items render highlight background across full pane width (`p_inner_x..(p_inner_x + p_avail_w)`).
- **Complete Theme Token Parity & Hit-Testing Invariant:** Every style in `ResolvedThemeStyles` (including `title`, `window_close_button`, `footer`, `highlight`, `highlight_text`, `border`, `text`, `accent`, `gutter`, `scrollbar`) must be registered in `ThemeEditorState::tokens`, with preview flash spans in `get_token_preview_spans`, hit-test bounds in `hit_test_preview`, and distinct picker titles.
- **Theme Editor Attribute Configuration & Dedicated Modals Invariant:** Non-color theme attributes in `themeedit` (`indicator`, `marquee.char`, `divider.char`, `wallpaper`) reside under `Theme:` with dedicated dialogs (`InputModal`, `AsciiGridModal`, `FilePickerModal`). Customization accepts strings, Unicode, CP437 macros (`{ascii:NNN}`), and Nerd Font macros (`{nf:...}`). Tokens never cycle hardcoded literals. Sidebar displays resolved glyphs and raw macros; `<Delete>` resets to default.

## 3. Terminal Safety & UI Performance Invariants
- **Modal Markdown Heading and Table Rendering (`MessageModal`):** `MessageModal` parses and renders markdown headings (`##`) and pipe tables (`| ... |`) with box-drawing borders (`┌─┬─┐`, `├─┼─┤`, `└─┴─┘`), wrapped cells, and BBCode (`[b]...[/b]`). Modal width adaptively clamps to table columns (up to 96 cols). When overflowing `content_h`, it renders a scrollbar (`▲`, `█`, `░`, `▼`) with keyboard and mouse scrolling.
- **Inactivity Timeout Reset Contract on External Program Return:** Spawning external programs, child subshells, editors, or companion CLI tools suspends idle tracking. Immediately upon returning to the main menu event loop, `last_activity` must reset (`last_activity = Instant::now()`). Time spent interacting with external commands must never count toward `inactivity_timeout`.
- **Tab Stop Traversal Order Invariant (Top-to-Bottom, Left-to-Right):** In dialogs, forms, and composite interfaces (e.g. 'Save As'), tab navigation progresses in visual order: top to bottom, left to right. Dialogs load with focus on uppermost control (e.g. file browser list). <kbd>Tab</kbd> advances sequentially downward and right (File List -> 'File name:' input -> `[ Save ]` -> `[ Cancel ]` -> cycle). <kbd>Shift+Tab</kbd> reverses traversal identically.
- **Form Navigation, Text Input Horizontal Scrolling & Modal Viewports Invariant:** Modal option lists (`ItemTypePickerModal`) dynamic-size height to screen bounds with vertical scroll indicators (`▲`/`▼`). Single-line inputs (`TextInput`) track `scroll_offset` keeping cursor visible on Left/Right/Home/End navigation, and support mouse click/drag text selection and checkbox toggling.
- **Contextual Modal Autofocus & Asset Directory Invariant:** Multi-field dialogs opened from specific tree tokens or settings (`BackgroundConfigModal`) must autofocus directly on the clicked/selected setting. File and wallpaper pickers prioritize `$REPO_DIR/assets/wallpapers` and user wallpaper directories before falling back to system paths.
- **Terminal Panic Hook Invariant:** Always install the global panic recovery hook (`bashmenu_tui::install_panic_hook()`) before terminal raw mode initialization to reset raw mode, leave alternate screen buffer, and restore cursor on panic.
- **Flicker-Free Alternate Screen Suspension & Synchronized Redraw (`TerminalGuard`):** When spawning child TUIs (`bashedit`, `menuedit`, `themeedit`, `bmpager`) or `alt_buffer: true` commands, use `guard.suspend_keep_alt(...)` (setting `BASHMENU_CHILD_ALT=1`). Use `guard.suspend(...)` only when `alt_buffer: false`. Never call `terminal.clear()` (`\x1b[2J`) on resume/reload; use `guard.request_clear()` and `guard.draw(...)` (DEC Mode 2026 synchronized output).
- **Full System Refresh (`<F5>`) Without Layout Jumps:** `<F5>` in `bashmenu` clears command cache, reloads `bashmenu.yml`, `bashmenu.mnu` (preserving navigation via `MenuView::reload_menu`), `bashmenu.themes`, wallpapers (reusing cached textures via `WallpaperCompositor::set_config` if unchanged), status/help gutters, and triggers forced plugin refresh (`trigger_refresh(&config, true)`) while keeping existing cached plugin rows visible until new outputs arrive.
- **Companion Tool Delegation (`bashedit` `<F6>`):** Markdown preview (`<F6>`) in `bashedit` delegates to `bmpager --markdown --no-file <temp_file>` via `guard.suspend_keep_alt` rather than using a duplicate built-in modal.
- **Immediate Mouse Interaction:** Handle `MouseEventKind::Down(MouseButton::Left)` directly rather than waiting for `MouseUp` or `Click` for instantaneous feedback without perceptible lag.
- **Icon Slot Width Invariant:** Main menu icon slots must always be exactly 4 visual columns wide (`vis_w + pad_w = 4`) regardless of glyph width or variation selectors.
- **Menu Priority Over Plugins:** When terminal viewport height is constrained, plugin rows must automatically truncate or drop first so menu items and status gutter remain completely visible.
- **Modal View Selection & Background Invariant:** Text inside modal frames inherits the modal frame's `styles.background`. Active/highlighted items or selectable links in note viewers use inverted text (`Modifier::REVERSED`) rather than glyph markers (`►`) or clashing highlight fills.
- **Unicode-Safe Text Editing & Universal Clipboard:** Single-line (`TextInput`) and multi-line text editors (`bashedit`, `NoteEditorModal`, `menuedit`) must operate on Unicode `char` counts (never byte slices), soft-wrap at word boundaries (`wrap_chars_by_word`), and support `Shift+Directional` selection plus `Ctrl+C` / `Ctrl+V` / `Ctrl+X` clipboard operations (`bashmenu_tui::clipboard`).
- **Spread Help Gutters, Strict Function Key Order & Dynamic Sizing:** Help gutters use up to 2 lines above bottom border, treating `|` as delimiter (`wrap_spread_help_gutter`) and spreading items across width. Omit `[UP/DN]: Nav` across all views. Function keys `<F1>`..`<F12>` in gutters must ALWAYS be in strictly ascending order. Gutter widths balance dynamically. Panel titles connect directly to borders (`┌─[ Title ]───`). Scrollable views reserve 1 row above bottom border and render scrollbar 1 column inside right border when overflowing.
- **Status Gutter Precedence & Date/Time Retention:** Status gutter takes layout precedence over help gutter. In narrow terminals (80 columns) with multiple active status tokens (user, battery, host, date/time), help gutter yields columns to ensure no trailing status tokens or date/time stamps are dropped or truncated.
- **Toast Notification Dispatch Invariant:** Non-blocking toasts (`{toast:SECONDS:"MESSAGE"}` or `type: toast`) dock in bottom-right corner above status gutter with accent block `▌` (`\u{258c}`), theme panel background, bold title, and wrapped body. Dismiss on timeout or mouse click. When `{toast:...}` leaves an empty command string, never execute an external shell.
- **Universal Marquee Overflow Invariant:** Text in panels, windows, viewports, lists, and titles (e.g. menu items, plugin rows, tree nodes, inspector lines, sidebar tokens, preview panes) that exceeds panel or window width margins must always marquee via `get_marquee_slice` using active theme's `marquee.char` and `marquee.gap`. Selection shifts reset ticker with 4-tick (1.0s) pause delay; pauses while modals are active. Input text boxes (`TextInput`) are strictly exempted and scroll horizontally via cursor offset without marqueeing.
- **TUI Border Multi-Byte Visual Width Invariant:** When constructing borders and calculating dialog padding, always measure text and icon width using visual terminal columns (`UnicodeWidthStr::width()`), never byte length (`.len()`). Multi-byte UTF-8 glyphs (`▲`, `▼`, `•`, `▌`) will otherwise offset corners and indent borders.
- **Modal Text Clamping & Word Wrapping Invariant:** Text inside popup modals MUST NEVER exceed visible window width; wrap (e.g. `wrap_prompt_text`) or safely clip within available inner columns to prevent spilling outside or onto borders.
- **Modal Frame Close Button Invariant (`is_close_button_clicked`):** Every popup dialog rendered via `render_modal_frame` displays an `[X]` close button at top-right of its frame. All modal `handle_mouse` implementations MUST test `is_close_button_clicked(inner, mouse.row, mouse.column)` and return `Some(None)` or cancellation on click. Parent loops must pass proper viewport rects to modals so frame geometries resolve accurately.
- **File and Directory Picker Hidden Files Invariant (`FilePickerModal`):** `FilePickerModal` must support toggling dotfiles visibility via <kbd>h</kbd>, <kbd>H</kbd>, <kbd>.</kbd>, and <kbd>Ctrl+H</kbd>, and via interactive button (`[h] Show Hidden` / `[h] Hide Hidden`) on the bottom bar, preserving selected paths across directory reloads.
- **Mandatory Screen Transitions, Modal Zoom Animations & Zero-Dimension Guard Invariant:** Visual screen transitions (`settings.transition`: `fade`, `curtain`, `dissolve`, `matrix`, `slide_left`, `slide_right`, `blinds`, `iris`, `wipedown`) and speed profiles (`settings.transition_speed`: `fast`, `normal`, `slow`, or ms) run across screen changes unless disabled (`transition: false`). Popup modals use zoom animations (`settings.modal_animation`: `zoom`, `none`) expanding from initiating row (or screen center) on open and shrinking on close. Transition routines (`draw_with_transition`, `draw_with_transition_out`, `draw_modal_grow`, `draw_modal_shrink`) must short-circuit on zero dimensions (`width == 0 || height == 0`) to avoid sleep delays in headless runs.
- **Editor Bounded Undo Stack Invariant (`bashedit`):** `EditorBuffer` caps undo history at 100 snapshots to prevent runaway heap allocations. Undoing beyond the 100-snapshot bounded capacity must safely and gracefully return `false` without crashing.
- **Gutter Text Width Calculation & BBCode Bracket Safety Invariant:** In help gutters, footers, and status bars with bracketed shortcuts (`[s] Save`, `[b] Back`), never use BBCode stripping to calculate visible widths or token positions: BBCode engines strip single-letter tags (`[s]`, `[b]`), causing width undercounts that shift tokens and corrupt borders (`Exitxi`). Always measure visible columns via `UnicodeWidthStr::width()` and clamp line rendering to `avail_w`.
- **Text Input Area Cursor Color Parity Invariant:** Throughout all tools (`bashmenu`, `menuedit`, `themeedit`, `bashedit`, `shortcutedit`, and modal inputs), the cursor style for any active text input area (`TextInput`) must match the text color being edited, visually harmonizing with the input field's foreground style.

## 4. Testing & Code Quality Invariants
- Before committing, always verify:
  1. Formatting: `cargo fmt --all --check`
  2. Compiler & Clippy Lints: `cargo clippy --workspace --all-targets -- -D warnings` (treat all Clippy warnings as errors)
  3. Tests: `cargo test --workspace`
  4. Shell Scripts: `shellcheck *.sh scripts/*.sh`
- In terminal scripts, do not assume `/usr/local/bin` for non-root users; install user CLI tools to `$HOME/.local/bin`.
- **Script Header Standard:** All shell scripts must begin with `#!/usr/bin/env bash` followed by a header comment (`SCRIPT: <name>.sh`, `DESCRIPTION: <summary>`).
- **Shellcheck Scope Invariant:** Verify shell scripts using `shellcheck *.sh scripts/*.sh` so extension scripts in `scripts/` are checked alongside root scripts.
- **Self-Contained Implementation & No External Tool Dependencies Invariant:** BashMenu must never rely on external tools or window managers (`kmscon`, `fbterm`, DEs) for core features. All functionality is native Rust within workspace crates. In environments lacking 24-bit TrueColor (e.g. Linux VT `TERM=linux`), the application detects capabilities and falls back to configured 16/8-color theme palette tiers.
- **Cargo Integration Test Binary Scoping (`CARGO_BIN_EXE_<bin>`):** Cargo sets `env!("CARGO_BIN_EXE_<bin>")` only for binaries defined within the same crate. CLI integration tests for specific binaries (`bashedit`, `bashmenu`, `bmpager`) must be located inside that specific crate's `tests/` directory.
- **Multi-Crate Cargo Binary Test Invocation (`-p <pkg> --bin <bin>`):** When invoking workspace executables via `Command::new("cargo")` in cross-crate integration tests, always pass `-p <package> --bin <binary>`. Calling `cargo run --bin <binary>` without `-p` fails in multi-crate workspaces when the target binary is not in default root package.
- **Doc Comment Line Length Invariant (<80 chars):** All `///` and `//!` doc comments across all workspace crates must strictly wrap at or under 80 columns.
- **Forbidden Keybindings (<kbd>F11</kbd>):** Never bind `<F11>` anywhere in interactive navigation or child TUIs; `<F11>` is reserved by Linux desktop window managers for fullscreen toggle. Use `<F12>` or alternate unreserved keys.
- **Code Safety & Error Handling (No Naked Panics):** Avoid naked `.unwrap()` and `.expect()` in interactive runtime loops, macro interpolation, or file parsing. Return strongly-typed errors using `thiserror` (`BashMenuError`) or propagate via `anyhow::Result` / `color_eyre::Result` at the binary boundary.
- **No Endless Loops Without Escape Paths:** Never construct interactive event loops or modal states that lack a dedicated escape/exit key sequence (`ESC`, `q`, `Ctrl+C`).
- **No Hardcoded Absolute Paths:** Never hardcode absolute user paths; always use dynamic resolving macros (`{home}`, `{bashmenu_dir}`, `{scripts_dir}`, `{templates_dir}`, `{cache_dir}`, `{dev_dir}`).
- **CP437 ASCII Macro Interpolation Invariant (`{ascii:NNN}`):** Any code reading theme glyphs or configuration strings must translate `{ascii:NNN}` macros to CP437 bytes. Raw `{ascii:NNN}` strings must NEVER appear unexpanded in visible menu options, indicators, or status lines.
- **Universal Documentation & 6-Tier Parity Invariant:** Every crate, module, struct, enum, and public function must have `///` doc comments (wrapped under 80 characters). When introducing or extending placeholders, macros, directives, options, or flags, update all six documentation tiers:
  1. Built-in help/reference modal in `bashmenu-tui`
  2. Inspector guide help modal in `menuedit-cli`
  3. Editor manual modal in `bashedit-cli`
  4. Pager manual modal in `bmpager-cli`
  5. Markdown guide (`bashmenu.md`)
  6. Linux man page (`bashmenu.1`)

## 5. TODO Task Execution & Lifecycle Invariants (CRITICAL)
- **Sequential TODO Execution:** Unless specifically labeled (`CRITICAL`) or explicitly instructed otherwise by the user, always tackle items from TODO lists (`~/.config/bashmenu/notebooks/notes.yml` under `'TODO (Agent: Allowed)'` or `.agents/skills/bashmenu-rs-developer/TODO.md`) strictly in sequential order, top to bottom. Complete each item fully (including verification, commit, push, and remote CI check) before moving to the next.
- **Task Precedence:** Order of priority when tasks conflict is `CRITICAL` / `CRITICAL BUG`, then `BUG`, `RESPONSIVENESS`, `UI`, `FEATURE`, `REQUEST`, and `RESEARCH`.
- **Add Unlisted Instructions:** If given an instruction not in a TODO list, you MUST add the instruction to the TODO list before working on it.
- **Pending Marker (`PENDING`):** When working on a TODO item, you MUST mark it as `PENDING` (`- [ ] PENDING: ...`). When completed, remove the `PENDING` label and mark it as complete (`- [x] ...`).
- **Log to `DONE.md` & Prune Finished Tasks:** Append a summary of every completed task to `.agents/skills/bashmenu-rs-developer/DONE.md`. When there are no more tasks to complete, remove finished (`- [x]`) tasks from the TODO list, and re-check the TODO list to ensure no new tasks were added.
- **Long-Running Process Periodic Status Updates:** When working on long running processes (tasks taking more than 1 minute), give a short status update at least every 2 minutes.

## 6. Installation & Uninstallation Invariants

### Installer (`install.sh`)
- **Workspace Compilation:** Must compile all binaries in release mode (`cargo build --release --workspace`).
- **Binary Installation:** Must install all 8 workspace binaries into `$BIN_DIR` (`$HOME/.local/bin` or `$PREFIX/bin` or `/usr/local/bin`):
  `bashmenu`, `ymlcheck`, `menuedit`, `shortcutedit`, `themeedit`, `bashedit`, `bmpager`, `cheat`.
- **Convenience Symlinks:** Must link `bm` -> `bashmenu`.
- **Manual Page Installation:** Must install `bashmenu.1` to `$MAN_DIR` (`$HOME/.local/share/man/man1` or system equivalent).
- **Configuration Seeding:** Must copy initial default config files (`bashmenu.yml`, `bashmenu.mnu`, `bashmenu.themes`, `shortcuts.yml`, `cheat.yml`) from project root into `~/.config/bashmenu/` without overwriting existing user files.
- **Output Banner:** The summary of installed commands displayed to user must explicitly list `cheat` along with all other tools.

### Uninstaller (`uninstall.sh`)
- **Complete Binary Cleanup:** Must remove all installed binaries and symlinks (`bashmenu`, `bm`, `ymlcheck`, `menuedit`, `shortcutedit`, `themeedit`, `bashedit`, `bmpager`, `cheat`) from `$BIN_DIR`.
- **Manual Page Cleanup:** Must remove installed manual page `bashmenu.1` from `$MAN_DIR`.
- **Settings Preservation:** Interactive mode must prompt the user whether to keep their settings and notebooks in `~/.config/bashmenu` with default of **Yes (Keep)** (`[Y/n]`). Supports non-interactive flags `-k`/`--keep-settings`/`--keep-config` (keep), `--remove-settings`/`--remove-config` (remove), and `-y`/`--yes` (non-interactive).
